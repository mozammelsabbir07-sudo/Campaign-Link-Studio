# Contributing

Thanks for considering a contribution to Campaign Link Studio.

## Good first contributions

- Report a reproducible bug with browser and steps.
- Improve keyboard navigation or screen-reader clarity.
- Add tests for URL edge cases.
- Improve the UTM naming guidance in the README.
- Propose a feature with a clear use case.

## Before opening a pull request

1. Explain the problem the change solves.
2. Keep the project dependency-free unless a dependency is clearly justified.
3. Test with URLs that already have query parameters and URL fragments.
4. Check the page at mobile and desktop widths.
5. Never add analytics or remote data collection without explicit discussion and documentation.

Please be respectful and constructive in issues and reviews.
